# Electrocatalysis (J) experiment

## Start here

**Question.** Can a COF's electrocatalytic activity be predicted from its monomers? Does correcting for differences between papers (each paper is a "batch") help? Does splitting monomers into main and side chains help?

**Data.** 55 COF/CTF materials with a measured `JD_max` (maximum diffusion current density, most likely for oxygen reduction) from **27 papers**. J is negative, and **a more negative J is a better catalyst**. About 89% of the variance in J is between papers: each lab measures on its own setup.

**Main findings** (details and numbers are in [analysis.ipynb](analysis.ipynb)):

1. **Absolute J for a new paper can't be predicted.** With leave-one-paper-out, the best R² of J is 0.07, and nearly every model is below 0, with or without correction. A random split looks better (R² up to about 0.3) only because a model can recognise which paper a material comes from.
2. **Correcting for the paper makes ranking within a paper possible.**
   - Per-paper z-scoring of J is the best of the five correction methods.
   - The best model, a random forest on ECFP trained on the 49 clean rows, orders **85–90%** of same-paper pairs correctly (chance is 50%). No within-paper shuffle reached that (permutation p < 0.01).
   - The result depends on the setup: it needs ECFP features and the clean rows. On all 55 rows it drops to 0.5–0.6, and with EState + functional groups to 0.4–0.5.
3. **The main/side split gives no consistent gain**, with or without correction. This matches the capacitance experiments ([../ctf_substrate_split/](../ctf_substrate_split/), PR #3, PR #5).

**For explainability:** run `final_model.py` (below). It fits the best configuration on all papers and saves the model, SHAP values and the substructure behind each ECFP bit. That is the model to explain.

## Run

From the repo root, with the main environment:

```bash
export PYTHONPATH=.
.venv/bin/python experiments/electrocatalysis/clean.py          # only if the spreadsheet changes; needs the xlsx
.venv/bin/python experiments/electrocatalysis/features.py       # about 1 min
.venv/bin/python experiments/electrocatalysis/run.py            # about 30 min on an M1 Pro; finished runs are skipped
.venv/bin/python experiments/electrocatalysis/permutation.py    # about 20 min
.venv/bin/python experiments/electrocatalysis/final_model.py    # seconds; --subset/--method/--model/--table override config.yaml
```

Then run `analysis.ipynb`. TabPFN is off by default (`tabpfn.enabled` in the config); it adds about 50 minutes on CPU.

## Explainability: using the final model

`final_model.py` writes these files to `results/final_model/<subset>__<method>__<model>__<table>/`:

| file | content |
|---|---|
| `model.joblib`, `scaler.joblib` | Fitted model. Its input is `scaler.transform(features)`, with features in the column order of `training_data.csv` |
| `training_data.csv` | One row per material: id, name, paper, J, the corrected target, and the unscaled features |
| `shap_values.csv` | SHAP value of every feature for every material |
| `importance.csv` | Per feature: mean \|SHAP\|, mean SHAP, `direction` (correlation of feature value with SHAP), and in how many materials it is present |
| `ecfp_bits.csv` | For each ECFP bit, the substructures that set it and in how many materials. `[r0]` is a single atom type; `[r1]`/`[r2]` is an atom with its neighbours up to 1/2 bonds away. Bits of the split features are mapped on the main or side fragment. |

**Things to keep in mind:**

- **The target is z-scored J within each paper**, so SHAP values are in units of "standard deviations within a paper".
- **A positive SHAP value or `direction` means a higher (less negative) J, i.e. a worse catalyst.** Negative means better.
- **SHAP is computed on the training materials themselves.** For a held-out view, `results/runs/.../importance.csv` has mean |SHAP| on the leave-paper-out test rows for every configuration.
- **Only 49 materials and 39 within-paper pairs.** Wang2024 (6 materials) contributes many of the pairs, so check whether an explanation is driven by one paper.
- **Feature names:** whole-monomer ECFP features are `ecfp_<bit>`; split ECFP features are `main_ecfp_<bit>` / `side_ecfp_<bit>`; MACCS features are `full_`/`main_`/`side_maccs_<key>`; `is_ctf` marks CTFs.

## Setup

**Cleaning ([clean.py](clean.py)):**
- **Fixed automatically:**
  - hydrazide groups written as `ONN`, replaced with `C(=O)NN` (rows 57–59)
  - a `[Br-]` counter-ion (row 59)
  - broken aromatic drawings (rows 28, 38, 39, 41), each replaced by the correct SMILES of the same skeleton found elsewhere in the file
- **Flagged as suspect:**
  - rows 22, 28, 50, 53 and 54: monomers that don't match the material's name or class
  - row 67: a broken drawing with no correct match
- **Subsets:** `all` keeps every row; `clean` drops the suspect rows.

**Features ([features.py](features.py)).** Julia's feature sets from `configs/best_feature_generation.yaml` plus MACCS, each in three variants:

| feature set | content |
|---|---|
| `ecfp` | ECFP4 counts, 1024 bits |
| `rf_best` | EState + functional groups |
| `brr_best` | descriptor + ECFP + EState + functional groups |
| `maccs` | MACCS key counts |

The variants are `a1_full` (whole monomers), `a2_main_side` (main ‖ side) and `a3_all` (both). A COF's two monomers are joined into one SMILES (`A.B`), and the split is done per monomer with `modules/features/substrate_split.py`. 28 of the 55 materials have side chains. Low-variance features are removed (threshold from Julia's config), and an `is_ctf` flag is added.

**Correction methods ([corrections.py](corrections.py)).** Each is fitted on the training papers only:

| method | what it does to J |
|---|---|
| `none` | Raw J |
| `center` | Subtracts each paper's mean. Single-material papers are dropped. |
| `zscore` | Subtracts each paper's mean and divides by its spread. Single-material papers are dropped. |
| `combat` | ComBat for one variable: empirical-Bayes shrinkage of each paper's mean and spread toward the average paper. All papers are kept. |
| `mixed` | A random intercept per paper, learned jointly with the model (MERF-style; RF uses out-of-bag residuals). A new paper gets intercept 0. |

**Models:** BRR, random forest, XGBoost and KNN with the repo defaults (no tuning), plus a median baseline.

**Evaluation:**
- **Leave-one-paper-out** for every method. A repeated stratified 5-fold random split (10 repeats) is also run on raw J, to show how much a random split overstates performance.
- **Metrics:**
  - R² of J for an unseen paper (its offset is unknown)
  - R² within papers (deviations from each paper's mean)
  - within-paper pairwise accuracy (WPA), with a 95% bootstrap interval over papers

## Results

All numbers come from `analysis.ipynb`.

**Random split vs leave-paper-out.** With raw J and a random split, R² reaches about 0.3. With leave-paper-out, R² is at most 0.07 and below 0 for all but one configuration. Raw-J models also rank materials within a paper *worse* than chance (mean WPA 0.37–0.39). What separates papers points the opposite way to what separates materials inside one paper.

**Correction methods** (leave-paper-out, mean over 48 model × feature-table combinations):

| method | WPA, all | WPA, clean | R² within, clean |
|---|---|---|---|
| `none` | 0.39 | 0.37 | −0.92 |
| `center` | 0.49 | 0.53 | −0.06 |
| `zscore` | 0.51 | 0.55 | −0.01 |
| `combat` | 0.44 | 0.50 | −0.05 |
| `mixed` | 0.44 | 0.42 | −0.47 |

Plain per-paper correction works best. ComBat and the mixed model leave part of each paper's offset in J, and because structure and paper are confounded, the models use it to recognise the paper again. The averages hide a wide spread: most model × feature combinations stay near chance.

**Best configurations** (clean rows, z-score):

| configuration | WPA (95% CI) | R² within |
|---|---|---|
| RF · ECFP · a1 | 0.85 (0.76–0.98) | 0.17 |
| RF · ECFP · a2 | 0.85 (0.78–0.96) | 0.15 |
| RF · ECFP · a3 | 0.90 (0.81–1.00) | 0.18 |

The permutation test (`results/permutation.csv`, table in the notebook) shuffles J inside each paper 100 times. No shuffle reached these values. They were picked as the best of about 480 configurations, which 100 shuffles can't fully account for. In their favour, the result holds for all three variants, and ComBat + XGBoost reaches 0.79. On all 55 rows, the best is BRR · MACCS · a2 with z-score at 0.74. The 6 suspect rows clearly hurt, so the chemists' confirmation of them matters.

**Main/side split.** Within the same model, feature set and correction, a2 or a3 against a1 shows no consistent gain under any method. Without correction, a2 and a3 are slightly worse than a1 on average (−0.01). With correction they are slightly better on average (+0.00 to +0.07) and rarely worse, but only 0–3 of the 16 comparisons per method have a 95% interval above zero. The side-chain block carries 13–66% of the SHAP importance in a2, so the models use it, but it doesn't reliably improve ranking.

## Caveats

- Literature data: different labs and measurement setups; the paper offset is most of the variance.
- Few within-paper pairs (45 on all rows, 39 on clean rows), many of them from one paper (Wang2024).
- The cleaning fixes are best guesses until the chemists confirm them.
- No hyperparameter tuning.
- The variance filter is fitted on all rows (it is unsupervised, as in the main pipeline).
